# Pre-1.18 Biomes Work

This repository contains files related to
- attempting to understand biome generation in *Minecraft: Java Edition* Beta 1.8 - 1.17.1,
- utilizing such knowledge to find worlds with desired biome configurations, and
- ideally, filtering or recovering worldseeds using biome coordinates.
